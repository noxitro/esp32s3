⌨️ MacroPad 設定

未接続
Chrome / Edge でこのファイルを開き、接続後にキーを設定します。接続するとデバイスはconfigモード(LED一斉点滅)になります。
WiFi AP経由で接続中
設定を保存したら「configモード終了」を押してください(WiFi APは停止します)。

マクロ書式

そのまま書いた文字はタイプされます(英数字と記号のみ。日本語の直接入力は不可)。
{ENTER} {TAB} {ESC} {F1}〜{F12} {UP} {DOWN} … 特殊キー / {CTRL+C} {WIN+R} {CMD+SPACE} … 同時押し / {WAIT:500} … 500ms待機
IME: {ZENHAN}(Win 半角/全角) {EISU} {KANA}(Mac 英数/かな) {CTRL+SPACE}(Android)
メディア: {BROWSER}(ブラウザ起動) {VOL_UP} {VOL_DOWN} {MUTE} {MEDIA_PLAY}
